STEP 1

결제 페이지로 이동

로그인 후 화면 좌측 하단에 있는 계정 아이콘을 클릭하면 메뉴가 열립니다. "Upgrade plan"을 클릭합니다.

또는 브라우저 주소창에 claude.ai/settings/billing 을 직접 입력해도 됩니다.

ℹ️ 이미 Pro 플랜인 경우 "Manage subscription" 메뉴로 표시됩니다.
STEP 2

Pro 플랜 선택하기

요금제 비교 페이지에서 Pro 칸의 "Subscribe" 버튼을 클릭합니다.

STEP 3

결제 정보 입력 (Stripe)

Stripe 보안 결제 창이 열립니다. 아래 항목을 모두 입력하세요.

1234 5678 9012 3456
MM / YY

⚠️
한국 카드 결제 전 체크사항
• 해외 온라인 결제가 활성화되어 있어야 합니다.
• 카드사 앱 → 해외 결제 → "허용"으로 변경 후 시도하세요.
• VISA / Mastercard / AMEX 브랜드 카드 사용을 권장합니다.
STEP 4

구독 완료 확인

"Subscribe" 버튼을 클릭하면 결제가 처리됩니다. 완료 후 화면에 확인 메시지가 표시되며, 가입 이메일로 영수증이 발송됩니다.

🔄 구독은 매월 자동 갱신됩니다. 언제든지 Settings → Billing → Cancel subscription에서 취소할 수 있습니다.
💰 취소해도 현재 구독 기간이 끝날 때까지 Pro 기능을 계속 이용할 수 있습니다.

Settings → Billing → "Cancel subscription" 클릭
