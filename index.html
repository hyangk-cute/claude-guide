1

회원 가입 방법

STEP 1

claude.ai 접속

웹 브라우저(Chrome, Edge, Safari 등)를 열고 주소창에 claude.ai 를 입력한 후 Enter를 누릅니다.

화면 중앙 또는 우측 상단의 "Sign up" 버튼을 클릭합니다.

STEP 2

가입 방법 선택

3가지 방법 중 하나를 선택해 가입할 수 있습니다.

가입 방법특징
🔵 Google 계정으로 계속구글 계정이 있으면 가장 빠름 (한 번의 클릭)
🍎 Apple 계정으로 계속Apple ID 사용자에게 편리
📧 이메일로 가입직접 이메일·비밀번호 입력
STEP 3

이메일로 가입하는 경우

① 이메일 주소 입력 → "Continue" 버튼 클릭

② 이메일 인증 — 입력한 이메일로 인증 코드(6자리)가 발송됩니다. 이메일을 열어 코드를 확인하고 입력합니다.

✅ 인증 코드 이메일이 오지 않으면 스팸 폴더를 확인하세요. 5분 이내로 도착합니다.
STEP 4

이름 입력 및 약관 동의

성(First name)과 이름(Last name)을 입력하고, 이용약관 및 개인정보 처리방침에 동의합니다.

"Continue" 를 클릭하면 가입이 완료되고, 바로 Claude를 사용할 수 있습니다!

🎉 무료 플랜으로 즉시 사용 가능합니다. 일일 사용 한도 내에서 Claude와 대화할 수 있습니다.
2

Pro 버전 결제 방법

참고

요금제 비교

플랜가격주요 혜택
Free 무료 일일 사용 한도, Claude 3.5 Sonnet 접근
Pro $20 / 월 5배 더 많은 사용량, 최신 모델 우선 접근, Projects 기능, 파일 업로드 강화
Team $25~30 / 월·인 팀 협업, 관리자 기능, 더 높은 사용 한도
STEP 1

결제 페이지로 이동

로그인 후 좌측 하단의 계정 아이콘 또는 "Upgrade to Pro" 배너를 클릭합니다.

또는 직접 claude.ai/settings/billing 주소로 접속합니다.

STEP 2

Pro 플랜 선택

요금제 비교 화면에서 Pro 플랜의 "Subscribe" 버튼을 클릭합니다.

STEP 3

결제 정보 입력 (Stripe)

Stripe 결제 페이지가 열립니다. 아래 정보를 입력하세요:

입력 항목내용
Card number신용/체크카드 16자리 번호
Expiry date카드 만료일 (MM/YY)
CVC카드 뒷면 3자리 보안 코드
Name on card카드에 적힌 영문 이름
Country청구지 국가 선택
⚠️ 한국 카드의 경우 해외 결제가 활성화된 카드가 필요합니다. 은행 앱에서 해외 결제를 허용으로 변경한 후 시도하세요.
STEP 4

구독 확인 및 완료

"Subscribe" 버튼을 클릭하면 결제가 완료됩니다. 영수증이 이메일로 발송됩니다.

🔄 구독은 매월 자동 갱신됩니다. 언제든지 Settings → Billing에서 취소할 수 있습니다.
3

데스크탑 앱 설치 방법

🪟 Windows
🍎 macOS
STEP 1

다운로드 페이지 접속

브라우저에서 claude.ai/download 에 접속하거나, Claude 웹 화면 좌측 하단 메뉴에서 "Download the app"을 클릭합니다.

STEP 2

🪟 Windows — 설치 파일 다운로드

"Download for Windows" 버튼을 클릭하면 Claude-Setup-x64.exe 파일이 다운로드됩니다.

STEP 3

🪟 Windows — 설치 실행

다운로드된 .exe 파일을 더블클릭하여 실행합니다.

Windows Defender 보안 경고가 뜨면 "추가 정보" → "실행"을 클릭합니다. 설치는 자동으로 완료되며, 완료 후 Claude 앱이 자동으로 실행됩니다.

🛡️ Windows SmartScreen 경고가 나타날 수 있습니다. "추가 정보"를 클릭한 뒤 "실행"을 선택하면 설치가 진행됩니다.
STEP 4

앱 실행 및 로그인

설치된 Claude 앱을 실행하면 로그인 화면이 나타납니다. 가입 시 사용한 계정으로 로그인합니다.

🚀 데스크탑 앱은 시스템 트레이에 상주하여 단축키로 빠르게 호출할 수 있습니다. (기본: Alt + Space / Windows 기준)
